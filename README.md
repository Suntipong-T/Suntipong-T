## 🌟 Featured Work

A few of the systems I've built and maintained:

- **💧 Water Situation & Forecasting Dashboards** — Dashboards for water operations (e.g. `รายงานสรุปสถานการณ์น้ำท่า`) built with Next.js, DaisyUI, and Tailwind — KPI cards, flood summary tables, map-based flood filters, and AI-generated summaries, integrating multiple flood models (Mike 11, ANNs, ML/Smart, SWAMP).
- **🌧️ Rainfall Forecasting App** — A Next.js app visualizing WRF model rainfall data by province on an interactive Leaflet choropleth map, with a Python pipeline (GeoPandas/Shapely) for spatial aggregation of meteorological grid data.
- **📡 IoT Monitoring Platform (Node-RED)** — Cloud + local Node-RED flows for real-time water level, gate, and CCTV monitoring, using MQTT, InfluxDB for time-series data, and PostgreSQL for relational/config data, with role-based JWT authentication.
- **🗺️ Interactive Basin Management Diagrams** — SVG-based interactive diagrams of Thai river basins with React overlay components for real-time data visualization.
- **📱 AquaGuard** — A mobile-first Next.js water monitoring app with a Node-RED backend, including QR-based device onboarding and custom SVG data visualizations.
- **🎓 CPA Tutoring Platform** — A full-stack tutoring platform with a CMS-managed admin panel, custom JWT auth, and real-time check-in tracking via Supabase Realtime.
